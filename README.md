# نظام الإسناد واللجان وأعمال الاختبارات

نظام ويب لمدرسة بلاط الشهداء الثانوية لإعداد أعمال الاختبارات وطباعتها: الإسناد، اللجان والكروكي، كشوف المناداة، المحاضر، التكليفات، والحقائب الجاهزة (حقيبة اليوم، كل الأيام، والملف الشامل) بصيغ الطباعة وPDF وWord وExcel.

## البنية
| المجلد | المحتوى |
|---|---|
| `src/` | المصدر: الواجهة (`index.src.html`)، المنطق (`app.js`، `home.js`)، البيانات الافتراضية (`data.js`)، وسكربت البناء |
| `site/` | الملفات المنشورة على Netlify (تُولَّد من `src/`) |
| `tooling/` | المكتبات بإصدارات مثبتة |

## التعديل والنشر
```bash
cd tooling && npm ci --ignore-scripts && cd ..
python3 src/build.py   # يولّد site/ ونسخة الملف الواحد single/
```
كل دفع إلى الفرع `main` يُنشر تلقائياً على Netlify.

## الخصوصية
بيانات الطلاب والمعلمين التي تُرفع داخل الموقع تُحفظ في متصفح الجهاز فقط، ولا تُرسل إلى أي خادم ولا تُخزن في هذا المستودع.
